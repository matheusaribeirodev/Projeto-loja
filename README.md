# 🛒 Loja Virtual (E-commerce)

Este é um projeto de e-commerce desenvolvido com uma arquitetura moderna e leve, utilizando **PHP** combinado com a linguagem **Hack** (HHVM) para tipagem estática e alta performance, **SQLite** para gerenciamento de banco de dados sem dependências externas complexas, e **Docker** para padronizar e facilitar o ambiente de execução.

---

## 🚀 Tecnologias Utilizadas

* **[PHP](https://www.php.net/)**: Linguagem de script principal do backend.
* **[Hack (HHVM)](https://hhvm.com/)**: Linguagem baseada em PHP que traz tipagem estática e assincronicidade.
* **[SQLite](https://www.sqlite.org/index.html):** Banco de dados relacional leve baseado em arquivo.
* **[Docker & Dockerfile](https://www.docker.com/)**: Containerização para garantir que o ambiente rode de forma idêntica em qualquer máquina.

---

## 📋 Funcionalidades

* 🛍️ Listagem de produtos disponíveis.
* 🛒 Campo de clientes.
* 📦 Gerenciamento de vendas.
* 🗃️ Banco de dados local integrado e rápido com SQLite.
